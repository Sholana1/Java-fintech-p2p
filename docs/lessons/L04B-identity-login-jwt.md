## 1. Story

Tolu logs in once. For the next 10 minutes every request carries a signed pass that any of our services can check in microseconds, without calling identity-service.
If someone edits the pass to say TIER_3, or forges one with their own key, every service must reject it.

## 2. Goal

`POST /auth/login` returns an RS256-signed JWT. `GET /auth/me` only works with a valid one. `GET /.well-known/jwks.json` publishes the public key so other services can verify tokens on their own.

package com.fintechdemo.identity.domain.model;

import java.time.Duration;
import java.time.Instant;
import java.util.Objects;

/** A signed, short-lived access token (a JWT) and its lifetime. */
public record AccessToken(String value, Instant issuedAt, Instant expiresAt) {

    public AccessToken {
        Objects.requireNonNull(value, "value");
        Objects.requireNonNull(issuedAt, "issuedAt");
        Objects.requireNonNull(expiresAt, "expiresAt");
    }

    public long expiresInSeconds() {
        return Duration.between(issuedAt, expiresAt).toSeconds();
    }

    // A token is a bearer credential: whoever holds it is the customer. Never print it.
    @Override
    public String toString() {
        return "AccessToken[value=***, expiresAt=" + expiresAt + "]";
    }
}

package com.fintechdemo.identity.application.service;

import com.fintechdemo.identity.application.port.in.LoginCommand;
import com.fintechdemo.identity.application.port.in.LoginUseCase;
import com.fintechdemo.identity.application.port.out.AccessTokenIssuerPort;
import com.fintechdemo.identity.application.port.out.CustomerPort;
import com.fintechdemo.identity.application.port.out.PasswordHasherPort;
import com.fintechdemo.identity.domain.exception.InvalidCredentialsException;
import com.fintechdemo.identity.domain.model.AccessToken;
import com.fintechdemo.identity.domain.model.Customer;
import com.fintechdemo.identity.domain.model.PasswordHash;
import com.fintechdemo.identity.domain.model.PhoneNumber;
import java.time.Clock;
import java.util.Optional;
import java.util.UUID;
import org.springframework.stereotype.Service;

/**
 * Logs a customer in. An unknown phone number still costs one full Argon2 check (against a decoy hash),
 * so response time does not reveal whether the number is registered.
 */
@Service
public class LoginService implements LoginUseCase {

    private final CustomerPort customers;
    private final PasswordHasherPort passwordHasher;
    private final AccessTokenIssuerPort accessTokens;
    private final Clock clock;
    private final PasswordHash decoyHash;

    public LoginService(CustomerPort customers, PasswordHasherPort passwordHasher,
            AccessTokenIssuerPort accessTokens, Clock clock) {
        this.customers = customers;
        this.passwordHasher = passwordHasher;
        this.accessTokens = accessTokens;
        this.clock = clock;
        this.decoyHash = passwordHasher.hash(UUID.randomUUID().toString());
    }

    @Override
    public AccessToken login(LoginCommand command) {
        Optional<Customer> customer = customers.findByPhoneNumber(new PhoneNumber(command.phoneNumber()));
        PasswordHash hashToCheck = customer.map(Customer::passwordHash).orElse(decoyHash);

        boolean passwordMatches = passwordHasher.matches(command.password(), hashToCheck);
        if (customer.isEmpty() || !passwordMatches) {
            throw new InvalidCredentialsException();
        }
        return accessTokens.issue(customer.get(), clock.instant());
    }
}

 * Publishes our PUBLIC signing key as a JWK Set (RFC 7517). The gateway and other services fetch it
 * to verify tokens themselves; they never need, and never get, the private key.

@RestController
public class JwksController {

        this.publicJwks = new JWKSet(signingKey.toPublicJWK()).toJSONObject();
    }

    @GetMapping("/.well-known/jwks.json")
    public Map<String, Object> jwks() {
        return publicJwks;
    }
}

```java
package com.fintechdemo.identity.adapter.out.persistence;

import com.fintechdemo.identity.application.port.out.CustomerPort;
import com.fintechdemo.identity.domain.exception.CustomerAlreadyExistsException;
import com.fintechdemo.identity.domain.model.Customer;
import com.fintechdemo.identity.domain.model.PhoneNumber;
import java.sql.SQLException;
import java.util.Optional;
import org.springframework.dao.DataIntegrityViolationException;
import org.springframework.stereotype.Component;

/**
 * CustomerPort backed by PostgreSQL via JPA.
 * No "SELECT ... WHERE phone = ?" check first: two registrations racing would both pass it.
 * The UNIQUE constraints decide, atomically; we translate their violation into a domain exception.
 */
@Component
class JpaCustomerAdapter implements CustomerPort {

    // PostgreSQL error code for unique_violation (Appendix A of the PostgreSQL docs).
    private static final String UNIQUE_VIOLATION = "23505";

    private final CustomerJpaRepository repository;

    JpaCustomerAdapter(CustomerJpaRepository repository) {
        this.repository = repository;
    }

    @Override
    public void add(Customer customer) {
        try {
            // saveAndFlush: run the INSERT now, inside this try, not later at commit time.
            repository.saveAndFlush(CustomerPersistenceMapper.toEntity(customer));
        } catch (DataIntegrityViolationException violation) {
            if (isUniqueViolation(violation)) {
                throw new CustomerAlreadyExistsException();
            }
            throw violation; // NOT NULL or CHECK failed: that is a bug, not a duplicate.
        }
    }

    @Override
    public Optional<Customer> findByPhoneNumber(PhoneNumber phoneNumber) {
        return repository.findByPhoneNumber(phoneNumber.value()).map(CustomerPersistenceMapper::toDomain);
    }

    private static boolean isUniqueViolation(DataIntegrityViolationException violation) {
        return violation.getMostSpecificCause() instanceof SQLException sql
                && UNIQUE_VIOLATION.equals(sql.getSQLState());
    }
}

package com.fintechdemo.identity.adapter.out.security;

import com.fintechdemo.identity.application.port.out.AccessTokenIssuerPort;
import com.fintechdemo.identity.config.JwtProperties;
import com.fintechdemo.identity.domain.model.AccessToken;
import com.fintechdemo.identity.domain.model.Customer;
import java.time.Instant;
import java.util.List;
import java.util.UUID;
import org.springframework.security.oauth2.jose.jws.SignatureAlgorithm;
import org.springframework.security.oauth2.jwt.JwsHeader;
import org.springframework.security.oauth2.jwt.JwtClaimsSet;
import org.springframework.security.oauth2.jwt.JwtEncoder;
import org.springframework.security.oauth2.jwt.JwtEncoderParameters;
import org.springframework.stereotype.Component;

/**
 * Signs RS256 JWT access tokens. The "kid" header names the key, so verifiers pick the right public key
 * from our JWKS, and we can rotate keys without breaking tokens already issued.
 */
@Component
class JwtAccessTokenIssuerAdapter implements AccessTokenIssuerPort {

    private final JwtEncoder encoder;
    private final JwtProperties properties;

    JwtAccessTokenIssuerAdapter(JwtEncoder encoder, JwtProperties properties) {
        this.encoder = encoder;
        this.properties = properties;
    }

    @Override
    public AccessToken issue(Customer customer, Instant now) {
        Instant expiresAt = now.plus(properties.accessTokenTtl());
        JwtClaimsSet claims = JwtClaimsSet.builder()
                .issuer(properties.issuer())
                .audience(List.of(properties.audience()))
                .subject(customer.id().value().toString())
                .issuedAt(now)
                .expiresAt(expiresAt)
                .id(UUID.randomUUID().toString())
                .claim(AccessTokenIssuerPort.KYC_TIER_CLAIM, customer.kycTier().name())
                .build();
        JwsHeader header = JwsHeader.with(SignatureAlgorithm.RS256).keyId(properties.keyId()).build();

        String token = encoder.encode(JwtEncoderParameters.from(header, claims)).getTokenValue();
        return new AccessToken(token, now, expiresAt);
    }
}

import com.nimbusds.jose.jwk.JWKSet;

import java.io.IOException;
import java.io.InputStream;
import java.security.interfaces.RSAPrivateKey;
import java.security.interfaces.RSAPublicKey;
import java.util.List;
import org.springframework.boot.context.properties.EnableConfigurationProperties;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.converter.RsaKeyConverters;
import org.springframework.security.oauth2.core.DelegatingOAuth2TokenValidator;
import org.springframework.security.oauth2.jwt.JwtClaimNames;
import org.springframework.security.oauth2.jwt.JwtClaimValidator;

import org.springframework.security.oauth2.jwt.NimbusJwtDecoder;

/** Loads the RSA key pair (PEM files) and builds the JWT encoder (signing) and decoder (verifying). */
@Configuration
@EnableConfigurationProperties(JwtProperties.class)
public class JwtConfig {

    @Bean
    RSAKey signingKey(JwtProperties properties) throws IOException {
        RSAPublicKey publicKey;
        RSAPrivateKey privateKey;
        try (InputStream in = properties.publicKeyLocation().getInputStream()) {
            publicKey = RsaKeyConverters.x509().convert(in);

            privateKey = RsaKeyConverters.pkcs8().convert(in);
        }
        return new RSAKey.Builder(publicKey).privateKey(privateKey).keyID(properties.keyId()).build();
    }

    @Bean
    JwtEncoder jwtEncoder(RSAKey signingKey) {
        return new NimbusJwtEncoder(new ImmutableJWKSet<>(new JWKSet(signingKey)));
    }

    /** Verifies signature and expiry (defaults), plus OUR issuer and OUR audience: anything else is rejected. */
    @Bean
    JwtDecoder jwtDecoder(RSAKey signingKey, JwtProperties properties) throws JOSEException {
        NimbusJwtDecoder decoder = NimbusJwtDecoder.withPublicKey(signingKey.toRSAPublicKey()).build();
        JwtClaimValidator<List<String>> audience = new JwtClaimValidator<>(JwtClaimNames.AUD,
                aud -> aud != null && aud.contains(properties.audience()));
        decoder.setJwtValidator(new DelegatingOAuth2TokenValidator<>(
                JwtValidators.createDefaultWithIssuer(properties.issuer()), audience));
        return decoder;
    }
}
```

    @Bean
    SecurityFilterChain apiSecurity(HttpSecurity http) throws Exception {

                        .requestMatchers(HttpMethod.GET, "/.well-known/jwks.json", "/actuator/health").permitAll()
                        .anyRequest().authenticated())
                .oauth2ResourceServer(oauth2 -> oauth2.jwt(Customizer.withDefaults()));
        return http.build();

## 5. Why

- **RS256 (asymmetric)**: only identity-service holds the private key; every other service verifies with the public key from `/.well-known/jwks.json`. Rejected: HS256 (shared secret), where every verifier could also mint tokens.
- **The decoder checks issuer and audience**, not just the signature and expiry. A valid token from some other issuer, or one meant for another API, is refused.
- **`kid` header**: lets us rotate keys. Publish the new key, sign with it, and old tokens still verify until they expire.
- **Short-lived (10 min) and stateless**: no session lookup on the hot path. The price is that a stolen access token works until it expires. Rotating refresh tokens with revocation (L04C) limits that window.
- **Decoy hash for unknown phones**: wrong password and unknown phone both run one Argon2 check and return the same 401 body, so login can't be used to find accounts. Verified: 0.115 s vs 0.103 s once warm.
- **Private key outside the repo** (`~/.fintechdemo/`): it can never be committed by accident. In production it would come from a secrets manager or KMS (L39).

## 7. Break it

Forge three tokens and present them to `/auth/me`:

1. Take Tolu's real token, decode the payload, change `TIER_1` to `TIER_3`, re-encode it, and keep the original signature.
2. Sign that TIER_3 payload with an attacker's own RSA key, using the same `kid`.
3. Send `{"alg":"none"}` with no signature at all.

✅ Verified: `401`, `401`, `401`. Changing any byte breaks the signature, and only our private key can produce a valid one.

## 8. Interview line

"identity-service signs short-lived RS256 JWTs with a private key that never leaves it, and publishes the public half as a JWKS, so the gateway and every service verify tokens locally in microseconds with no call back. Verification checks signature, expiry, issuer and audience, and a kid header lets us rotate keys without downtime. Login returns the same 401, in the same time, for a wrong password and an unknown phone number."
